# A 股量化分析工具（v0.1）

一个面向 A 股的个人量化研究脚本：自动下载日 K 线 → 计算技术指标与绩效 → 双均线策略回测与参数扫描 → 样本外验证 → 可视化。

> ⚠️ **免责声明**：本项目仅用于**学习与技术研究**，不构成任何投资建议。股市有风险，据此操作盈亏自负。

## ✨ 功能特性

- **数据获取**：腾讯证券日 K 线（前复权）为主数据源，新浪财经自动回退；带浏览器 UA 与指数退避重试
- **真实名称**：从腾讯接口解析股票真实名称（如「贵州茅台」）
- **技术指标**：MA5 / MA20 均线、RSI(14) 相对强弱指标、当日涨跌幅
- **绩效报告**：累计/年化收益率、年化波动率、夏普比率、最大回撤、胜率、盈亏比
- **策略回测**：双均线金叉/死叉引擎，信号次日生效（避免未来函数）
- **参数扫描**：12 组均线组合按夏普比率排名，附带「买入持有」基准对照
- **样本外验证**：前 70% 数据选参、后 30% 检验，判断是否过拟合
- **可视化**：3×2 综合看板 + 最优策略买卖点图（金叉▲ / 死叉▼）
- **数据落盘**：自动保存 CSV（`utf-8-sig` 编码，Excel 打开不乱码）

## 📦 环境要求

- Python 3.10+
- 需要联网（访问腾讯/新浪行情接口）
- 有图形界面的环境可弹窗看图；无 GUI 环境自动回退（不出图但报告照常输出）

## 🚀 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/Cyphone67/quant-journey.git
cd quant-journey

# 2. 创建虚拟环境并安装依赖（建议）
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt

# 3. 运行（两种方式任选）
python a_share_quant.py                 # 交互式输入股票代码（回车用默认 600519）
python a_share_quant.py 000001          # 命令行直接指定股票代码
```

支持的 A 股代码：`6` 开头（沪市）、`0` / `3` 开头（深市）。

## 📊 运行输出

1. **终端**：最近 10 个交易日表格 + 最新行情摘要 + 专业绩效报告
2. **参数扫描报告**：12 组 MA 组合按夏普排名 + 买入持有基准
3. **样本外验证报告**：样本内 vs 样本外对比 + 过拟合结论
4. **图表 1**：综合看板（价格+均线 / 成交量 / 累计收益 / 回撤 / 指标条形图 / KPI 面板）
5. **图表 2**：最优策略图（策略 vs 买入持有净值 + 买卖点）
6. **CSV 文件**：行情数据保存为 `<股票代码>.csv`

## 🔧 常见问题

- **数据下载失败**：多为网络原因（接口限流/断连），脚本会自动重试并在腾讯/新浪间回退；持续失败请检查网络后重试，或在有网环境先运行一次生成 `<ticker>.csv`，把 CSV 拷回离线环境再运行。
- **图表不弹出**：当前环境无图形界面（如服务器），脚本已自动回退到 Agg 后端，不影响报告与 CSV（图会以窗口方式显示的仅在有 GUI 的本地运行环境）。
- **中文显示方块**：matplotlib 未找到中文字体，可修改 `a_share_quant.py` 顶部的 `plt.rcParams["font.sans-serif"]` 加入你系统已有的字体，例如 `['Microsoft YaHei','SimHei']`。
